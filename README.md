# London Weather

A SwiftUI app. `Store` and `RootView` open `HomeView`. Forecast payloads decode into `CityWeather`, `Day`, and `Hour`. The home screen loads London’s current conditions, then a seven-day list that starts with today. Each day shows the weekday name, the high and low temperature, and the conditions text. Agent instructions are in `AGENTS.md`.

Open `LondonWeather.xcodeproj` in Xcode 16 or later, choose the **LondonWeather** scheme, and run it on an iPhone or iPad simulator. The deployment target is iOS 17.
