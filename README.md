# London Weather

A SwiftUI app. The first screen is `HomeView`. Forecast payloads decode into `CityWeather`, `Day`, and `Hour`. A weather service is not in the project yet.

Open `LondonWeather.xcodeproj` in Xcode 16 or later, choose the **LondonWeather** scheme, and run it on an iPhone or iPad simulator. The deployment target is iOS 17.
