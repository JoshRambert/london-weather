# London Weather

A SwiftUI app. `Store` and `RootView` open `HomeView`. Forecast payloads decode into `CityWeather`, `Day`, and `Hour`. A weather service is not in the project yet. Agent instructions are in `AGENTS.md`.

Open `LondonWeather.xcodeproj` in Xcode 16 or later, choose the **LondonWeather** scheme, and run it on an iPhone or iPad simulator. The deployment target is iOS 17.
